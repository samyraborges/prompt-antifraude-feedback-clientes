# Desafio Criativo — Extraindo Insights do Feedback de Clientes Bancários

Engenharia de prompts aplicada à análise de feedbacks bancários e identificação de possíveis padrões e fragilidades em antifraude.

## Prompt Final

Atue como especialista em antifraude em um banco.

Sua tarefa é analisar as contestações dos clientes para identificar os motivos relacionados às reclamações e entender o comportamento nas contratações de financiamentos de veículos, bens e serviços, e consignado, buscando identificar, com base nos dados fornecidos, possíveis concentrações de casos de Golpes/Falsidade Ideológica, conluio, autofraude e desacordo comercial.

Contexto: Trabalhar com feedbacks de clientes bancários relacionados à contratação de financiamentos de veículos, bens e serviços, e consignado. O resultado deverá identificar oportunidades para alimentar o time de estratégia de antifraude, apoiando na revisão de regras/políticas em novas contratações dos produtos.

Dados disponíveis: A base contém data da contestação, relato do cliente, documento do cliente, canal de reclamação, canal de contratação do produto, data da contratação do produto e loja responsável.

Instruções de análise:

1. Classifique os feedbacks por casos que contenham insumos mais completos, que sinalizem possíveis fragilidades para o banco e possíveis fragilidades na contratação do produto.
2. Identifique os principais padrões, problemas, elogios e oportunidades.
3. Aponte evidências nos dados fornecidos.
4. Sugira ações práticas para o time de estratégia de antifraude.

Formato da resposta: Entregue um resumo evidenciando as possíveis concentrações, os relatos mais citados e os comportamentos em comum, além de sugestões para mitigar novas manifestações.

Restrições:

- Use apenas os dados fornecidos.
- Não invente números, causas ou conclusões.
- Não exponha dados pessoais ou sensíveis.
- Informe limitações quando os dados não forem suficientes.
- Use linguagem técnica, explicativa e voltada para tomada de decisão.
